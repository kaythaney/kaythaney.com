Personal site of Kaitlin Thaney: open infrastructure work, writing, and ceramics (Clay Thaney).

- `index.html`: home
- `clay/index.html`: ceramics collections, Held & Keeping urns
- `writing/index.html`: The Open Stack archive
- `style.css`: shared styles
- `img/`: photos
